# jdk.base Skill

This repository retains the historical `jdk.base` v1 release and no longer publishes new versions. Use the `java.base` module supplied by Norm for new application code.

Follow the [migration example](examples/java-base/Main.norm) and the [official java.base declaration](https://github.com/normlanguage/Norm/blob/main/norm/stdlib/java/base/module.norm). Historical API declarations remain available at the [v1 tag](https://github.com/normlanguage/jdk-base/blob/v1/SKILL.md).
